## 2．clip を用いる表現子：新しい arms

新しい arms のモデル定義として，逆リンクの前に双対座標を訓練標本の最小値と最大値で clip する．処置群と対照群の枝は異なる定義域を持つため，各枝の訓練行から範囲を求める．held-out 点，内側の交差検証の評価点，functional が他方の処置を評価する点にも同じ訓練範囲を用いる．当てはめの目的関数は変更していない．元の arms は残し，失敗後に clip へ切り替える処理はない．非有限の双対座標は失敗として残る．

- `src/genriesz/glm.py`：`GRRGLM.__init__`，`fit`，`_fit_coefficients`，`_fit_strict`，`predict_v`，`_predict_v_unclipped`，`classify`，`derivative_alpha`．`clip_dual=False` が既定値．成功した訓練標本だけから `dual_bounds_` を設定する．
- `src/genriesz/estimation.py`：`grr_functional`．`riesz_clip_dual` を inner CV と outer fit に渡す．ARW と TMLE のすべての表現子評価が同じモデル定義を使う．
- `src/genriesz/model_selection.py`：`score_grr_candidate`，`select_grr_hyperparams`．inner fit ごとに範囲を求め，検証時にも clip を用いる．検証時の双対座標の functional も clip した座標から計算する．
- `notebooks/experiments/grrexp/e12.py`：arm の一覧，`generator`，`_grr_model`，`_grr_cf`，`stage0`，`summarise`，図表のラベル．追加は `BKL1_clip`，`BP_C1_clip`，`BP_C0_clip`．Stage 0 の予測は元の arms だけに用いる．
- `notebooks/experiments/grrexp/e21.py`：arm の一覧，`generator`，`model`，`s1_intervals`，`_row_label`．ATE に `lin-UKL1_clip` と `rkhs-UKL1_clip`，ATT に `lin-UKL0_clip` と `rkhs-UKL0_clip`．元の arms の bootstrap 乱数列を保つため，新しい arms の bootstrap は元の arms の後に行う．
- `notebooks/experiments/grrexp/e22.py`：arm の一覧，`_grr_arm`，`full_sample`，`_label`，`figure` のラベル．追加は `UKL-D1_clip`，`UKL-D2_clip`，`UKL-D3_clip`．
- テスト：`tests/test_grrexp_e12.py`，`tests/test_grrexp_e21.py`，`tests/test_grrexp_e22.py`．訓練時の係数と目的関数が同じであること，各枝の範囲，範囲の由来，functional の評価，inner CV，失敗後の状態，非有限値，元の bootstrap 乱数列を検証した．
